# MediPlant Gate Keeper (Plant vs Non-Plant Filter)

This package contains the pipeline to clean, split, train, evaluate, and export the **Stage 1 Plant Gate Model**.

---

## 1. Directory Structure

```
gate_keeper/
├── config.py                 # Hyperparameters, directories & class definitions
├── dataset/                  # Dataset directory
│   ├── plant/                # Raw plant images (leaves, flowers, foliage)
│   ├── non_plant/            # Raw non-plant images (objects, people, cars, rooms)
│   ├── train/                # 80% train split (generated by organize script)
│   │   ├── non_plant/
│   │   └── plant/
│   └── val/                  # 20% validation split (generated by organize script)
│       ├── non_plant/
│       └── plant/
├── organize_gate_dataset.py  # Cleans, deduplicates & partitions images into train/val
├── model.py                  # MobileNetV3-Small binary classification architecture
├── dataset_loader.py         # Data augmentations & PyTorch DataLoaders
├── train_gate.py             # Training loop with learning rate scheduler & checkpointing
├── evaluate_gate.py          # Validation classification report & confusion matrix
├── export_gate_onnx.py       # Converts PyTorch model to high-speed ONNX runtime model
└── test_gate.py              # CLI tool to test single image gate predictions
```

---

## 2. Step-by-Step Instructions

Open your terminal in `c:\Users\ANKIT SHANBHOG\Desktop\Backend\gate_keeper`:

### Step 1: Organize the Dataset
Reads your `dataset/plant` and `dataset/non_plant` folders, standardizes all images to valid JPEGs, eliminates duplicates, and splits them 80/20 into `dataset/train/` and `dataset/val/`:
```bash
python organize_gate_dataset.py
```

### Step 2: Train the Gate Model
Starts training the MobileNetV3-Small binary model:
```bash
# Standard training (15 epochs, batch size 32)
python train_gate.py

# Optional customization:
python train_gate.py --epochs 15 --batch-size 32 --lr 0.0003
```
* Best weights are saved automatically to `checkpoints/best_gate_model.pth`.

### Step 3: Evaluate the Model
Generates precision, recall, and a confusion matrix on the validation set:
```bash
python evaluate_gate.py
```

### Step 4: Export to ONNX (for Backend Deployment)
Exports the model into a lightweight ONNX file (~5 MB, executes in ~1.2ms on CPU):
```bash
python export_gate_onnx.py
```
* Generates `exports/plant_gate_model.onnx` and `exports/gate_classes.json`.

### Step 5: Test a Single Image
Test any image from your computer to see if it passes or gets rejected:
```bash
python test_gate.py --image path/to/sample_photo.jpg
```
